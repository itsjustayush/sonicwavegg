# Public interaction reference notes

The public gbrl.ai flow presents a deliberately minimal initial state with one clear entry action. Selecting that action moves the interface into a visible connection state with a single prominent animated audio visualization and concise status copy.

Sonic Morse will use these high-level principles independently: a focused **Start session** action, explicit **arming**, **connecting**, **transmitting**, and **received** states, and a central activity visualization that reflects its own custom multi-tone FSK packet lifecycle. It will retain its current Sonic Morse name, colors, information architecture, codec, and original visual assets; no reference-site branding, copy, source code, or graphical assets will be reused.
